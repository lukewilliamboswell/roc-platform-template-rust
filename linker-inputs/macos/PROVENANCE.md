# macOS linker-interface provenance

`libSystem.tbd` is generated by this repository from `interfaces.json`. It is
not copied from Xcode, an Apple SDK, or a macOS installation, and the generator
must not inspect those files. The catalog contains public symbol names selected
from documented Darwin C, POSIX, pthread, dynamic-loader and unwinding APIs and
is narrowed by native final-link testing of this project's Rust host.

The generated TAPI v4 document is a project-authored link-time interface only.
It contains no Apple implementation code. Catalog changes require review of the
public evidence links, both architecture spellings, and native macOS tests.
