# Linker input notices

The Linux inputs are compiled from the sources vendored by the checksum-pinned
Zig release. Their complete license texts are included in the archive:

- musl libc: MIT license; copyright holders listed in `licenses/musl.txt`.
- LLVM libunwind: Apache-2.0 WITH LLVM-exception; see `licenses/libunwind.txt`.
- Zig runtime and compiler support: MIT license; see `licenses/zig.txt`.

The macOS `.tbd` interface is generated by this project from public API names.
See `macos/PROVENANCE.md`; it is not copied from an Apple SDK.
