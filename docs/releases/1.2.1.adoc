= 1.2.1

This maintenance release strengthens source-policy checks, generated binding
validation and release evidence. It retains the platform interface and example
paths. Product release inventories describe the delivered files and retain
explicit missing supplier coverage.

The manual brings build, contribution, release and security instructions into
one place. Intel macOS remains cross-compiled only; the native compatibility
result covers Linux x86_64, Linux ARM64 and Apple Silicon macOS.

The Rust host and committed bindings now match the selected nightly glue. Host
implementers will see explicit ownership requirements on generated allocation
and reference-count helpers; the supplied host has been updated with them.
The public Roc interface remains unchanged.
