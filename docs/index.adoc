= Roc platform template for Rust
Luke Boswell
:doctype: book
:toc: left

Build a native Roc platform with a Rust host. Start with the released examples
if you want to write a Roc application. Start with the contributor chapter if
you want to change the host or the platform interface.

The https://github.com/lukewilliamboswell/roc-platform-template-rust/releases/latest[latest release]
contains a platform bundle and examples that name that exact bundle.
The https://lukewilliamboswell.github.io/roc-platform-template-rust/[API reference] describes the latest published platform;
this manual describes repository maintenance at version {docs-version}.
