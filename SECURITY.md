# Security

Report suspected vulnerabilities privately through [GitHub's vulnerability reporting form](https://github.com/lukewilliamboswell/roc-platform-template-rust/security/advisories/new). Do not include vulnerability details in a public issue or pull request before a fix is available.

Include the affected release, Roc compiler version, operating system and target, the expected and actual behavior, and a minimal reproduction when possible. Describe the potential impact and any workaround you found. Exclude credentials and personal information.

Security fixes target the latest platform release. Older releases do not receive automatic backports; update to the fixed release when one is available. The maintainer reviews reports and coordinates disclosure through the private advisory. No response-time guarantee is made.

See the [security guidance in the manual](https://lukewilliamboswell.github.io/roc-platform-template-rust/manual/security.html#report-a-vulnerability), or read the [manual sources](docs/index.adoc).
